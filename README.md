# TaskMaster

A premium, lightweight task manager application built to practice core frontend development concepts including CRUD operations, state management, and clean Vanilla JS architecture.

Users can create, edit, delete, and manage tasks with deadlines, helping them stay organized and prioritize effectively. The application features a real-time productivity tracker and a seamless Dark Mode experience.

## The Goal of This Project

The goal of this project was to:

- **Master Vanilla JS State Management**: Implementing a robust state-sync logic between the UI and LocalStorage without external frameworks.
- **Implement Scalable UI Architecture**: Building a professional "dashboard" layout using modern CSS Flexbox and SVG graphics.
- **Handle Complex Logic**: Working with date comparisons for deadline tracking and calculating real-time productivity percentages.
- **Focus on UX/UI Excellence**: Implementing features like Dark Mode, Drag-and-Drop, and responsive design for a premium user experience.

## Tech Stack

- **JavaScript (Vanilla)**: Core logic and DOM manipulation.
- **HTML5**: Semantic structure and SVG icons.
- **CSS3**: Professional theming with CSS Variables, Flexbox, and fluid typography.
- **LocalStorage**: Persistent data storage for a local-first user experience.

## Key Features

- **Add Tasks with Deadlines**: Include titles, descriptions, and due dates.
- **Productivity Tracker**: Real-time circular progress ring visualizing your completion rate.
- **Overdue System**: Automatic flagging and filtering of past-due tasks.
- **Dark Mode**: Fully themed experience with smooth transitions and system preference awareness.
- **Drag & Drop Reordering**: Intuitive task prioritization.
- **In-place Editing**: Quick title updates without leaving the dashboard.
- **Persistent State**: Your tasks and theme preferences stay saved in your browser.

## Why I Built This

As part of my journey toward becoming a frontend developer specializing in secure web systems, this project focuses on building strong fundamentals—understanding the browser APIs and CSS architecture—before scaling into more complex framework-based applications.
