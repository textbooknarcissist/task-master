# TaskMaster

A lightweight, premium-styled to-do list built with plain HTML, CSS, and JavaScript.

## Features
- Create, edit, complete, and delete tasks
- Filter by all, active, or completed
- Drag-and-drop reordering
- Clear completed tasks
- Persists tasks in LocalStorage

## Getting Started
1. Open `index.html` in your browser.
2. Start adding tasks.

Tip: Use a local static server if you prefer (for example, VS Code Live Server), but it is not required.

## Usage
- Add a task using the input field and `+` button.
- Click the circle to toggle completion.
- Double-click a task or use the edit button to rename it.
- Drag tasks to reorder them.
- Use filters to view subsets of tasks.
- Use "Clear Completed" to remove finished tasks.

## Project Structure
- `index.html` - markup
- `styles.css` - styling
- `app.js` - application logic

## Notes
- Tasks are stored in browser LocalStorage, so they persist between reloads on the same browser.
